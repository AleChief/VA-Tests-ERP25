# VA-Tests-ERP25
Сценарный тест Vanessa Automation «Производство с планированием по материальным и производственным ресурсам»
для конфигурации 1С:ERP Управление предприятием 2.5 (2.5.4.102 и выше).

## Откуда исходники

Первый коммит — тест из поставки 1С на ИТС «Тесты для автоматизированного тестирования УП» (архив от 16.04.2020)
без изменений: сценарий, библиотека шагов `БиблиотекаШагов.zip` и инструкция `Как запустить тест из поставки ERP.doc`.
Демобаза из архива (`BP.dt`) и конфигурация не публикуются. Права на тест принадлежат 1С.

## Что изменено и зачем

На актуальных версиях платформы и Vanessa Automation исходный тест падал плавающе, а проверка синтаксиса VA выдавала замечания.
Правки — отдельными коммитами поверх исходного теста, подробности — в сообщениях коммитов. Проверки сценария не
ослаблены.

- Синхронизация: ожидание гиперссылки отчёта в панели отчётов и вопроса «1С:Предприятие» с таймаутом.
- Синтаксис VA: удалены пустые группы шагов, заголовки окон с пробелом перед завершающим `*`.
- Комментарий о времени запуска (ниже).

## Время запуска

Четыре проверки отчёта «Загрузка видов рабочих центров по графику производства» — ожидания 1С без изменений; они
рассчитаны на запуск днём. Этапы производства планируются от текущего момента: при запуске ночью (примерно до 4–8 ч
по времени базы) этап 2.1.2 после перепланирования встаёт на день раньше, и отчёты 2–3 расходятся с эталоном.

## Проверено

1С:ERP 2.5.4.102 (демобаза из архива ИТС), платформа 8.3.24.1528, Vanessa Automation 1.2.043.47: сценарий целиком,
1621 шаг без ошибок — три дневных прогона.

Подготовка базы и запуск — `Как запустить тест из поставки ERP.doc`.

## Ветка file-base-env

Нужна только для запуска на файловой базе с лицензией для разработчиков; на обычном стенде не нужна. Это `main` плюс
окружение запуска, сценарий не меняется:

- `VAParams.json` — настройки VA для запуска набора из `<каталог теста>` на файловой базе `<каталог базы>`
  (пути заменить на свои): клиент «Администратор» с ключами `/Lru /VLru` (на Windows с английским интерфейсом без них
  стандартные команды платформы английские и тест падает на первом «Записать и закрыть»), библиотека шагов
  `Libraries`, остановка на первой ошибке, отчёты JUnit и Cucumber JSON;
- `Libraries\ПолучениеНавигационнойСсылки` — библиотека шагов из `БиблиотекаШагов.zip`, распакованная.

Подготовка базы из `BP.dt` (один раз, затем сохранить свой dt):
- у пользователя «Администратор» снять «Защиту от опасных действий» — иначе VA при каждом запуске спрашивает
  разрешение на открытие обработки (или `DisableUnsafeActionProtection=` в `conf.cfg`);
- способ проверки подписи мобильного клиента — «не проверять» (`SetMobileClientSignatureVerificationMethod(
  MobileClientSignatureVerificationMethod.DontVerifySignature)` через COM): иначе на 8.3.24 при каждом запуске клиента
  модальное «Подпись мобильного клиента … устарела», и VA не может подключить клиент.

Проверено так же: платформа 8.3.24.1528, Vanessa Automation 1.2.043.47, файловая база — 1621 шаг без ошибок.
