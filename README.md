# VA-Tests-ERP25
Сценарный тест Vanessa Automation «Производство с планированием по материальным и производственным ресурсам»
для конфигурации 1С:ERP Управление предприятием 2.5 (2.5.4.102 и выше).

## Откуда исходники

Это первый опубликованный фирмой «1С» сценарный тест Vanessa Automation для 1С:ERP. О публикации — новость на
Инфостарте «Опубликованы первые тесты Vanessa Automation для 1C:ERP» (02.06.2020):
https://infostart.ru/journal/news/mir-1s/opublikovany-pervye-testy-vanessa-automation-dlya-1c-erp_1244595/ .
Дистрибутив «Тесты для автоматизированного тестирования УП» для 1С:ERP 2.5.4.102 выложен для пользователей 1С:ERP и
фирм-партнёров в сервисе «1С:Обновление программ»; 1С предлагает внедренцам проверять этими сценариями свои
доработанные конфигурации.

Первый коммит — этот тест (архив от 16.04.2020) без изменений: сценарий, библиотека шагов `БиблиотекаШагов.zip` и
инструкция `Как запустить тест из поставки ERP.doc`. Демобаза из архива (`BP.dt`) и конфигурация не публикуются —
их нужно взять в «1С:Обновление программ». Права на тест принадлежат 1С.

## Что изменено и зачем

На актуальных версиях платформы и Vanessa Automation исходный тест падал плавающе, а проверка синтаксиса VA выдавала замечания.
Правки — отдельными коммитами поверх исходного теста, подробности — в сообщениях коммитов. Проверки сценария не
ослаблены.

- Синхронизация: ожидание гиперссылки отчёта в панели отчётов и вопроса «1С:Предприятие» с таймаутом.
- Синтаксис VA: удалены пустые группы шагов, заголовки окон с пробелом перед завершающим `*`.
- Комментарий о времени запуска (ниже).

## Время запуска

Четыре проверки отчёта «Загрузка видов рабочих центров по графику производства» — ожидания 1С без изменений; они
рассчитаны на запуск днём. Этапы производства планируются от текущего момента: при запуске ночью (примерно до 4–8 ч
по времени базы) этап 2.1.2 после перепланирования встаёт на день раньше, и отчёты 2–3 расходятся с эталоном.

## Проверено

1С:ERP 2.5.4.102 (демобаза из архива ИТС), платформа 8.3.24.1528, Vanessa Automation 1.2.043.47: сценарий целиком,
1621 шаг без ошибок — три дневных прогона.

Подготовка базы и запуск — `Как запустить тест из поставки ERP.doc`.

## Зачем этот репозиторий

Тренировка работы с ИИ-помощником: через MCP Vanessa Automation помощник прогоняет тест на тестовой базе,
разбирает падения по журналу и снимкам экрана и исправляет сценарий, а человек проверяет и принимает правки.
